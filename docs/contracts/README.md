# GridAware Machine-Readable Contracts

- `openapi.yaml`: OpenAPI 3.1 starter for representative public REST routes. The Markdown endpoint catalog is the broader MVP inventory.
- `asyncapi.yaml`: AsyncAPI 2.6 starter for MQTT publisher channels.
- `schemas/`: JSON Schema 2020-12 contracts for telemetry, device status, and anomaly inference request/response.

`gridaware.example` values are placeholders, not live hosts. Validate YAML, OpenAPI, AsyncAPI, external references, and JSON Schemas in CI before generation. A valid schema is not itself security or architecture approval.
