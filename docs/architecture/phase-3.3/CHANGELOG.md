# Phase 3.3 Documentation Changelog

- Added REST overview and complete MVP endpoint catalog.
- Added request/response, pagination, and error conventions.
- Added Membership-based human authorization and Device identity contracts.
- Added versioned MQTT topics, telemetry envelope, device status, and QoS semantics.
- Added WebSocket event envelope, subscription policy, and recovery requirements.
- Added BullMQ job catalog and transactional outbox semantics.
- Added internal Python inference request/response and error contracts.
- Added validation, idempotency, retry, ordering, and rate-limit rules.
- Added contract-test checklist, open decisions, review gate, and ADR-0006 through ADR-0009.
- Added draft OpenAPI, AsyncAPI, and JSON Schema artifacts.

This version is a technical design proposal. It does not imply implementation.
